# Nest Little Baby identity

Created with the built-in image-generation tool. The generated master is `nest-mark.png`; application icons and the ICO are resized derivatives of that master, with a warm ivory background for home-screen use.

## Generation prompt

Use case: logo-brand. Create a single premium minimal symbol for Nest Little Baby, a calm newborn care app. A sleeping little bird/baby nestled inside two protective curved leaf wings, the negative space subtly forming a heart. Refined organic silhouette, rounded generous shapes, flat vector-like edges, elegant Scandinavian nursery identity. Deep forest sage green #43634f with a tiny warm apricot #d9ad8a cheek/accent. Very simple readable at favicon size; balanced centered square composition, mark fills about 85% of canvas. Transparent background. Symbol only, NO letters, NO words, NO mockup, NO shadows, NO gradients, NO thin fragile lines. One finished logo mark only.
